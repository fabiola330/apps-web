Preguntas Frecuentes

¿Qué es un sitio web?
Es un conjunto de páginas web relacionadas que se pueden consultar en internet

¿Qué significa HTML y qué representa cada una de sus palabras?
Significa Lenguaje de Marcado Hipertexto, por sus siglas en inglés Hipert Text Markup Lenguage

Ejemplos de navegadores
  • Google
  • Edge
  • Mozilla Firefox
  • Brave

¿Quién interpreta las etiquetas HTML?
El navegador

¿Qué diferencias existen entre HTML y CSS?
HTML estructura el contenido de la pagina, CSS dedine su diseño y apariencia

¿Qué es CSS y cuál es su función principal?
CSS es un lenguaje de estilos que sirve para dar diseño y formato a una pagina web

¿Qué es un protocolo de comunicación en internet y por qué es necesario?
Conjunto de reglas para que los dispositivos puedan comunicarse y compartir información correctamente

Ejemplos de protocolos de internet
  • HTTP
  • HTTPS
  • FTP

Diferencia entre HTTP y HTTPS
HTTPS es la versión segura de HTTP porque cifra la información transmitida
